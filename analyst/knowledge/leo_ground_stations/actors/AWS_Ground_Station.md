# AWS Ground Station

## Overview
- **Type:** Tier-3 Cloud Platform GSaaS
- **HQ:** Seattle, Washington, USA
- **Ownership:** Amazon (NASDAQ: AMZN)
- **Founded:** 2019

## Network
- **Sites:** 12 (AWS regions)
- **Planned Expansion:** 300+ (via Kuiper constellation ground stations)

## Business Model
Cloud-integrated GSaaS — ground stations are an extension of AWS compute. Customers downlink directly into AWS cloud for processing.

## Recent Developments
- **Jan 2026:** Expanded GSaaS Partner Programme — KSAT and Skynopy join as partners
- AWS moving toward platform aggregation model (partner GSaaS operators) rather than building own sites
- Kuiper constellation (3,236 satellites) will have 300+ ground stations, co-located with AWS infrastructure

## Key Differentiator
Vertically integrated with Amazon's Project Kuiper constellation. 12 AWS regions provide cloud-edge processing. Partner programme model reduces capital intensity.

## Strategic Position
Hyperscaler cloud platform making ground segment a cloud service. Partner programme model creates Google Cloud-style aggregation layer. Potential exit from owned infrastructure (following Azure Orbital model) toward pure platform layer.
