# Skynopy

## Overview
- **Type:** Tier-2 VC-Backed GSaaS
- **Legal Entity:** Skynopy SAS
- **Incorporated:** France (Paris)
- **HQ:** Paris, France
- **Founded:** October 2023
- **Founders:** Pierre Bertrand (CEO, ex-Loft Orbital, MIT), Antonin Hirsch (CTO, ex-Loft Orbital)
- **Employees:** ~15

## Network
- **Sites:** 15+
- **Antennas:** 15+
- **Planned Expansion:** 100+ antennas by 2028 via 'massive agreement' with unnamed major industry partner
- **Business Model:** Hybrid — leases spare capacity from constellation operators (leveraging unused Starlink/OneWeb antennas) plus building own sites
- **Own-build sites:** Saint-Pierre et Miquelon (French territory, near Newfoundland), Réunion (French territory, Indian Ocean)
- **Partner:** Orange named as telecom partner
- **AKAR Project:** Unified high-speed real-time space network (target 2028)

## Key Differentiator
Fastest-growing GSaaS — founded 18 months ago, already 15+ stations and €18M in funding. CNES strategic investor provides French sovereign backing and access to French overseas territories for ground station placement.

## Concentric Assessment
> "Skynopy is the fastest-growing entrant. The French government (via CNES and BPI France) has strategic interest in sovereign ground infrastructure, which aligns with Concentric's government/defence positioning. Building own stations in French overseas territories (Saint-Pierre, Réunion) creates immediate site security requirements. The hybrid model of leasing spare constellation capacity is innovative but creates complex site access arrangements that would benefit from professional security management."

**Security implications:** French sovereign backing via CNES and BPI France aligns with government/defence security positioning. Own-build stations in French overseas territories create immediate site security needs. Hybrid model (lease + own) creates complex multi-party site access requiring professional security management.

**Concentric entry point:** Secondary target for Physical Security to GSaaS Providers.

## Strategic Position
France's national champion in GSaaS. Leveraging French overseas territories for strategic global coverage. Strong state backing (CNES, BPI France). AKAR project (2028) positions as next-gen high-speed network.
