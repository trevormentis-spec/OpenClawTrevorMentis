## Architecture — API Key Isolation (Option A)

**2026-05-20**: Implemented Option A per Roderick's directive — API key isolation to prevent scripts from bypassing the LLM routing architecture.

### What was built
- `_present_env.py` — shared env loader. `get_key("OPENROUTER_API_KEY")` raises `ValueError` explaining it must go through `analyst/llm_clients/`. Only non-LLM keys (GENVIRAL, MAPBOX, AGENTMAIL, GITHUB) can be loaded here.
- `present-runner.sh` — wrapper script that sets `PYTHONPATH` so `from analyst.llm_clients import *` works from any directory.

### Refactored scripts (route through analyst/llm_clients/ instead of reading .env directly)
- ✅ `qc_vision.py` — Opus 4.7 vision QC via `OpenRouterClient`
- ✅ `stage1_image.py` — GenViral key via `_present_env.get_key()`
- ✅ `stage3_map.py` — Mapbox token via `_present_env.get_key()`
- ✅ `trevor_present.py` — env via `_present_env.load_env()`
- ✅ `assemble_brief.py` — no .env reads needed (uses weasyprint only)
- ❌ `stage2_cover.py` — **still needs refactoring** (was restored from git, has direct Opus API calls + wrong `__future__` import order)
- ❌ `stage3_social.py` — **still needs refactoring** (same reason)
- ❌ `stage4_audio.py` — **still needs refactoring** (same reason)

### Pattern for remaining scripts
1. First line after shebang: `from __future__ import annotations`
2. Second: `import sys, pathlib; sys.path.insert(0, str(pathlib.Path(__file__).resolve().parent.parent.parent))`
3. Replace `_get_openrouter_key()` / direct API calls with `OpenRouterClient` from `analyst.llm_clients.openrouter_client`
4. Replace `.env` key reads with `from _present_env import get_key, load_env`
