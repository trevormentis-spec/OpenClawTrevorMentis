# Limitations and responsible use

## Not an AI detector

ProseBench does not decide whether text is human- or machine-authored. Style cannot establish provenance reliably, and detector optimization is not a writing objective.

## Not an autonomous high-stakes grader

A model report is a structured second-reader judgment. Consequential grading requires human authority, local calibration, announced criteria, and a review path.

## Source verification is incomplete

The MVP does not retrieve external sources. It can identify claims and citations for review and compare locked tokens across revisions. It cannot certify factual accuracy.

## Context and genre matter

Users should supply audience, purpose, genre, and any assignment brief. A profile can still be misapplied, and additional disciplinary profiles require validation.

## Language fairness

The initial implementation is English-first. Conventions should be judged by reader effect and actual task requirements, not conformity to one prestige dialect. Fairness testing remains essential.

## Scores are judgments

Decimal scores support comparison but are not physical measurements. Textual evidence and confidence matter more than a one-point difference.

## Provider drift

Model behavior and APIs change. Reports record the provider, model, profile version, and timestamp so results can be interpreted in context.
