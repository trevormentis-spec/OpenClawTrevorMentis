# Philby Desk Architecture — Future Plan (2026-05-27)

## Current State
2 Africa desks: `north_africa` + `sub_saharan_africa` — regional only.

## Proposed Hybrid Architecture

### 20-25 High-Signal Country Desks
Nigeria, South Africa, Kenya, Ethiopia, DRC, Egypt, Morocco, Algeria, Sudan, Somalia, Mozambique, Ghana, Senegal, Ivory Coast, Mali, Burkina Faso, Niger, Cameroon, Angola, Zimbabwe, Tunisia, Libya, Uganda, Rwanda, Tanzania.

### 5-6 Regional Umbrella Desks (for remaining ~30 smaller countries)
- **Sahel Cluster**: Chad, Mauritania
- **Gulf of Guinea**: Benin, Togo, Guinea, Liberia, Sierra Leone, Gambia, Guinea-Bissau, Cape Verde
- **Central Africa**: CAR, Congo, Gabon, Equatorial Guinea, São Tomé
- **Southern Africa**: Zambia, Botswana, Namibia, Malawi, Lesotho, Eswatini
- **Indian Ocean**: Madagascar, Mauritius, Seychelles, Comoros
- **Horn**: Djibouti, Eritrea, South Sudan

### 4-5 Cross-Cutting Thematic Desks (overlay across all country desks)
- Sahel Jihadism
- Maritime Security (Gulf of Guinea + Western Indian Ocean)
- Russia/Africa Corps
- China-Africa
- Critical Minerals

### Rationale
- Agents can consume more granularity than humans — 54 country desks is viable for ingestion
- But cross-border dynamics (jihadism, piracy, arms flows) don't respect borders
- Thematic overlays preserve cross-country connective tissue that pure country silos would lose
- Phased rollout: seed top 20 country desks first, add rest as source coverage validates
